# Taehun Kim CV — GitHub Pages

## 가장 쉬운 배포 방법

1. 본인의 GitHub 계정으로 로그인합니다.
2. 새 **Public repository**를 만들고 저장소 이름을 정확히 `YOUR_GITHUB_USERNAME.github.io`로 설정합니다.
3. 이 폴더의 `index.html`, `style.css`, `script.js`를 저장소의 최상위(root)에 업로드합니다.
4. `Settings → Pages`로 이동합니다.
5. Build and deployment에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, Folder는 `/ (root)`를 선택하고 Save합니다.
7. 몇 분 뒤 `https://YOUR_GITHUB_USERNAME.github.io/`로 접속합니다.

## 중요

웹페이지 코드는 README에 붙여 넣는 것이 아닙니다. GitHub Pages는 루트의 `index.html`을 웹페이지 시작 파일로 사용합니다. README.md는 설명용 문서입니다.

## 수정 위치

- CV 내용: `index.html`
- 영어/한국어 번역: `script.js`
- 파란색 배경/디자인: `style.css`
